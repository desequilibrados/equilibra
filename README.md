# 🥗 Equilibra

## 📌 Sobre o projeto

O **Equilibra** é um aplicativo voltado para **saúde e bem-estar**, desenvolvido com o objetivo de auxiliar os usuários na organização de sua alimentação.

A proposta do projeto é permitir que o usuário informe algumas de suas características e objetivos, como **idade, peso, altura, nível de atividade física e objetivo**, para que o sistema possa utilizar essas informações na elaboração de uma sugestão de plano alimentar personalizado.

O projeto está sendo desenvolvido como parte da disciplina de **Gestão e Qualidade de Software (GQS)**.

---

## 🎯 Problema

Muitas pessoas possuem dificuldades para organizar sua alimentação de acordo com suas características, rotina e objetivos.

Além disso, nem sempre o usuário sabe quais informações considerar ao montar uma rotina alimentar, tornando difícil estabelecer uma alimentação organizada.

O Equilibra busca oferecer uma ferramenta simples que auxilie o usuário nesse processo.

---

## 💡 Solução

O Equilibra pretende utilizar os dados fornecidos pelo usuário para gerar uma **sugestão de plano alimentar**, buscando proporcionar uma experiência simples e personalizada.

O funcionamento planejado será:

1. O usuário informa seus dados;
2. O sistema recebe e processa essas informações;
3. O sistema considera o objetivo informado pelo usuário;
4. É gerada uma sugestão de plano alimentar;
5. O usuário poderá visualizar as informações do seu plano.

> **Observação:** o Equilibra tem finalidade acadêmica e de auxílio à organização alimentar. As sugestões apresentadas pelo sistema não substituem o acompanhamento de profissionais da área da saúde.

O projeto está relacionado à **ODS 3 — Saúde e Bem-Estar**, tendo como foco contribuir para hábitos mais saudáveis e para uma melhor organização da alimentação.

A escolha da ODS está diretamente relacionada à proposta do Equilibra de utilizar a tecnologia como ferramenta de apoio à saúde e ao bem-estar.

---

## 👥 Público-alvo

O aplicativo será destinado a pessoas que desejam:

- Organizar melhor sua alimentação;
- Ter uma sugestão de alimentação baseada em seus dados;
- Acompanhar seus objetivos relacionados à alimentação;
- Utilizar uma ferramenta simples para auxiliar na criação de uma rotina alimentar.

---

## ⚙️ Funcionalidades planejadas

### Cadastro de informações

O usuário poderá informar dados como:

- Nome;
- Idade;
- Peso;
- Altura;
- Nível de atividade física;
- Objetivo;
- Preferências ou restrições alimentares.

### Geração do plano alimentar

A partir das informações fornecidas, o sistema deverá processar os dados e gerar uma sugestão de plano alimentar.

### Visualização

O usuário poderá visualizar as informações e refeições sugeridas pelo sistema.
